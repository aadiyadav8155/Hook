# React Counter App

This project provides a minimal setup to get a React Counter working with basic state management and custom CSS styling.

Currently, two core functionalities are available:

- **Increment & Decrement** uses the `useState` hook
- **Zero-limit constraint** ensures the value never drops below zero

## Styling and UI

External CSS frameworks are not enabled on this template to keep the setup lightweight. To modify the design, edit the `App.css` file which uses vanilla CSS gradients, flexbox, and soft shadows.

## Expanding the State Management

If you are developing a more complex application, we recommend moving beyond local state. Check out the official React documentation for information on how to integrate Context API or Redux in your project.
